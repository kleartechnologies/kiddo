Proposed · v2

Head takes more of the frame

r 50 → 58 in the same 200-unit box. Head-to-body reads closer to 1:1, which is what makes a character read as a child rather than a mascot.

Eyes more than double

r 7 → 15.5, with a white catchlight and a second soft glint. Brows are added as separate strokes so an expression can change without moving the eyes.

A muzzle, a nose and an open mouth

Today the face is two dots and a line. The mouth now opens with a tongue, which is where nearly all of the warmth in the reference comes from.

Two canon rules this breaks — decide before build

RULE 01 says no gradients and lighter forms as white overlay. v2 uses a two-stop radial per hue and a real cream fill; that is the whole difference between flat and soft. characters.ts says KIDDO “belongs to no species”. The reference draws a bear cub. Both are cheap to keep instead — say the word and I'll flatten the fills and drop the bear ears.

Embedded in a scene, not pasted on top

The rig's four pivots are unchanged, so these are the existing point, wonder and celebrate poses. What is new is that the character stands on the world's ground, overlaps its props, and casts a contact shadow onto it.

Construction canon v2

One 200 × 240 box, five characters. Every number below is shared, which is what makes them a family rather than five drawings — and it is the same kind of file canon.ts already is.

Head r 58 · eyes r 15.5

Eye spacing 48, eye line y 92. PIP and WALLY use white sclera with a r 10–11.5 pupil; the other three use solid ink with a catchlight.

Four pivots, unchanged

Shoulders (46,150) / (154,150), hips (80,188) / (120,188). Every pose in poses.ts still tweens.

One identity marker each

Round ears · pointed ears + tail · long ears + bow · eyes-on-top · spout. Each survives a 48px silhouette test with no colour at all.

One accessory each

Star satchel · red bandana · heart satchel · yellow bowtie · red scarf. The accessory is how a child tells two greens apart in a group shot.

Shading: two stops, one direction

Radial from 34% / 24%, light → base → deep. Every character lit from the same upper-left. No third stop, no rim light, no outline.

Compact below 64px

Crop to 34 12 132 124 — the head and the marker. Limbs, accessory and shading drop; the flat base hue carries it.

Honest note on production

Everything on this page is hand-written SVG, so it ships as-is inside components/character with no new dependency, no raster assets and no build step — the rig, the pose table and the expression table all survive. What SVG cannot reach is the reference's fur texture and painterly edges. If you want that specific finish, these drawings become the model sheet a commissioned illustrator works from, and characters.ts's existing art: {} field is already the hook that swaps them in per size.

I cannot generate illustrated artwork — everything here is drawn as vector shapes by hand. Say the word if you'd like the flat-fill version to compare, or a different species read on any of the five.
