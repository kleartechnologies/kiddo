Audit P0-1, answered

Ground band, three depth layers, the apple tree, flowers, WALLY standing in his own garden, and the round's actual first-board items already growing. composeIntro keeps its three slots — friend, preview, begin — so this is a scene change, not an architecture change.

The preview never leaks the answer

introPreviewOf already returns prompt items, never options. Three apples at three sizes says “this is about apples” without saying how many.

Difficulty visual language

Easy carries lucide's Check in sprout ink. Medium carries ArrowRight and takes a tide fill when chosen. Hard carries Lock until it opens — still focusable, still announced. Never colour alone; never “you are losing”. The tier only changes which plan is dealt.

Hard is exciting, never scary

The escalation is more world, not darker world: at Hard the garden gains butterflies and a second tree. Same sky, same sun, same friendly host line.

04 · Connect — live

general-knowledge.home-partners · travel

Tap an animal, then tap where it lives. Homes are on different rows from their animals on purpose: DUCK rises one row, BIRD crosses two. The travel vector is derived from the destination node's own coordinates, so it cannot point anywhere else.

The camel bug, structurally prevented

Nodes are laid out at declared coordinates rather than measured after the fact. Travel is destination − origin on both axes, read from the node the child actually tapped. DUCK travels +98 down, BIRD travels −196 up. A one-axis animation is not expressible here: there is no code path that moves x without y.

Audit P0-3: the first touch is invited

Before any selection the homes wear the existing static dashed-tide invited look, so the board says “these are the places” without an arrow, a flash or a loop. It re-appears whenever an animal is held.

Audit P2-10: the board settles

A finished join leaves a faded paw print where the animal stood, so the end state reads “everyone went home” instead of three empty pills.

Creatures, not columns

The nodes: "creature" token already says “no card”. The animals stand on the land, the homes are drawn where they belong — pond by the water, nest on a branch, burrow in the mound — and the join is the existing join: "path" dotted trail.

Accessibility unchanged

78px targets, real buttons, full instruction in aria-label (“Duck. Choose where it lives.” → “Pond. Duck lives here.”), state never colour alone (check badge + paw print), and travel disabled under prefers-reduced-motion — the animal is simply home.

Choice: a creature on its own ground

Wide tiles rather than a square grid, because a phone has more width than height. Each animal stands on a small contact shadow so it is on the land the world already drew. The caption stays — a picture plus its word is the middle rung of the PICTURE → WORD → SYMBOL ladder.

Counting: things in a place, signs in the ground

Five apples standing on the grass, five signs on posts. Exactly the tiles: "sign" and prompt: "open" tokens the Counting Garden already declares — the post is decoration below the target, never part of it.

Audit P1-4, answered by presentation

Bare pips inside a garden were the audit's first-door complaint. Drawn apples on grass cost no content change — counting-objects already deals them; this is what they should look like.

Wrong is never red

Apricot surface, magnifier badge, tile stays tappable, question stays on screen. No cross anywhere, no shake — the existing single settle. Try Duck or Sheep and see.
